# フォームスタイル for kintone

無料版で、区切り方式のタブ・スクロール移動・入力状況チップ・共通テーマを使えます。

## 導入

Releasesから `form-style-3.0.0-free-bundle.zip` を取得して展開し、中の `form-style-3.0.0-free-plugin.zip` を展開せずkintoneに読み込んでください。設定後はアプリを更新します。

PC版のレコード追加・編集・詳細が対象です。無料版と＋版は同じIDなので、同じドメイン内の利用アプリ全体が切り替わります。既存プラグインは削除しないでください。

＋版は表示項目の選択・共有、項目名検索、個別装飾に対応。税込5,500円・買い切りです。

[紹介・利用方法](https://www.nestrec.com/form-style) / [試用版](https://www.nestrec.com/product-page/form-style-plus-trial) / [＋版](https://www.nestrec.com/product-page/form-style-plus)

配布はプラグインZIPと利用ガイドです。ソースの公開やOSSライセンスの付与を行うリポジトリではありません。
